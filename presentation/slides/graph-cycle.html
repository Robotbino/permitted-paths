Read the four steps. The run obeys a procedure. The run reads facts from the knowledge graph. The run writes its steps to the context graph. Good runs become a better procedure.

Read the colours. Blue boxes are about control. Amber boxes are about data. A context graph is a graph of traces. It is not the context window of a model.
