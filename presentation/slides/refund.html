Part 0 · the claim

An agent gets a small task: “Add a refund button to the order page.” It writes an endpoint, and the endpoint operates. Then a customer clicks the button two times, and gets two refunds.

No sentence in the prompt stopped it.

GE 00

Start here, because everyone in the room has seen a version of this. The agent did nothing wrong by its own lights. The prompt asked for a refund button and it built one. Nothing in the prompt said that an order can be refunded at most once — and a prompt could not have enforced it anyway.
