Part 6 · the factory

One design that uses all three controls

A software factory is a workflow that you can do again and again to make software. Agents do the steps for which judgment is necessary. Code does the other steps.

LayerWhat it isControl
1. Domain ontologyWhat is permitted in a game storeControl 2: fewer permitted results
2. Engineering knowledge graphRequirements, rules, code, testsControl 2, for the codebase
3. Execution graphThe factory line, with gates on itControls 1 and 3
4. Traces and memoryWhat each run did. The lessons go back to layer 2.The improvement of all three

Twelve numbered nodes do the work of a change. Four contain a model, code does seven, and a person does one. Each cycle has a maximum number of attempts; at the maximum, the run goes to a person.

The domain ontology says what is permitted in the business. The engineering knowledge graph says where each rule is in the code. They are two different graphs with two different jobs.
