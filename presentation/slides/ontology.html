Part 4 · control 2

A prompt asks the model to obey a rule. An ontology makes the rule a check for each result.

Back to part 1: you asked for the status of order 1042 five times. The correct status is PAID. An ontology says which words exist at all, so four of the five answers stop being a matter of opinion.

The model suggests a result. The ontology rejects each result that is not permitted. Constraints on the types also increase the number of useful queries: a smaller number of types gives a smaller number of queries that have no relation to the question.

GE 04 §1–3

An ontology is not documentation. It is an enumeration, a set of types and a set of rules that something in the system can actually run against a candidate answer.
