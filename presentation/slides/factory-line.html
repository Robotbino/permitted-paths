Four nodes contain a model: 1, 3, 6 and 9. Code does seven nodes. A person does one node. Most of the line is not a model.

The writer is not the examiner. The agent that writes the code cannot write the test report, and it cannot change the rule tests. Node 9 did not write the change.

PART 6

Read the colours along the line: a model or an agent is always followed by code that checks its work. Intake is followed by retrieval, the plan by the plan gate, the implementation by the tests and the rule gate, the review by the pull request with the evidence. Nodes 11 and 12 are the intelligence plane at work: record the trace, then put the lessons back into the knowledge graph.
