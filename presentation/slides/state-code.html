The state contract

@dataclass(frozen=True)
class RunState:
    run_id:     str
    request:    str
    kind:       Literal["question", "change"] | None = None
    plan:       str | None = None
    approved:   bool = False
    attempts:   int = 0
    tests_pass: bool = False
    facts:      tuple[Fact, ...] = ()

    # a node never mutates. It returns the next state.
    def with_(self, **kw) -> "RunState":
        return replace(self, **kw)

Node = Callable[[RunState], RunState]

Why frozen

Every node has the same signature: a state in, a new state out. Nothing else crosses a node boundary — no globals, no hidden writes to the database.

Why it is small

If a field is not on this class, no edge can branch on it. Keeping the state small keeps the set of possible paths small, which is the point.

What you get for free

Each state is a value you can store, compare and replay. A failed run becomes a test: load the state before the bad step and run that one node.

attempts lives on the state so the edge, not the model, can count

The frozen dataclass is doing real work here. Because a node cannot reach around the state to change the world, you can throw a step away after a gate rejects it. That is what makes the pure-agent rule on the gates slide affordable.
