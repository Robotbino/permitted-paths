The state contract

state

what goes from node to node

@dataclass(frozen=True)
class RunState:
    run_id:     str
    request:    str
    kind:       Literal["question", "change"] | None = None
    plan:       str | None = None
    approved:   bool = False
    attempts:   int = 0
    tests_pass: bool = False
    facts:      tuple[Fact, ...] = ()

    # a node does not change the state. It gives the next state.
    def with_(self, **kw) -> "RunState":
        return replace(self, **kw)

Node = Callable[[RunState], RunState]

Why frozen

Each node has the same shape: a state in, a new state out. No other data goes across the edge of a node.

Why small

If a field is not in this class, no edge can use it to select a path. A small state gives a small number of possible paths.

What you get

You can keep each state, compare it and use it again. A failed run becomes a test: load the state before the bad step, and do that one node.

attempts is in the state. Thus the edge counts, not the model.

PART 2

The frozen dataclass is doing real work here. Because a node cannot reach around the state to change the world, you can throw a step away after a gate rejects it. That is what makes the pure-agent rule on the gates slide affordable.
