Part 2 · the four parts: nodes, edges, state, control

A node is not always a model call

code

Fixed step

Code. No model.

Predictable: fully

model

Model step

One model call with no tools.

Predictable: not fully

agent

Agent step

A model that uses tools in a loop.

Predictable: less than a model step

code

Verifier

A check of the work of a different node.

Predictable: fully, if it is code

person

Person step

A person gives approval or rejects.

Predictable: fully, as a point in the path

A test for a node. Write what the node does in one sentence with no “and”. If you cannot do this, divide the node.

Edges. A fixed edge: node B always comes after node A. A conditional edge: a function reads the state and gives the name of the next node.

State and control. The state goes from node to node. The control is the runtime: it enforces the edges and counts the attempts.
