Part 2 · the four parts: nodes, edges, state, control

A node is not always a model call

Type of nodeWhat it containsPredictable?
Fixed step — codeCode. No model.Fully
Model stepOne model call with no toolsNot fully
Agent stepA model that uses tools in a loopLess than a model step
Verifier — codeA check of the work of a different nodeFully, if it is code
Person stepA person gives approval or rejectsFully, as a point in the path

A test for a node. Write what the node does in one sentence with no “and”. If you cannot do this, divide the node.

Edges. A fixed edge: node B always comes after node A. A conditional edge by code: a function reads the state and names the next node. The model chooses only where you let it.

State and control. The state is what passes between nodes. The control is the runtime that enforces the edges, counts the attempts and decides what “complete” means.
