Gate 1: is the shape of the call correct?

gate 1

before the tool operates · reads only the call

class RefundCall(BaseModel):
    model_config = ConfigDict(extra="forbid")
    order_id:     int
    amount_cents: PositiveInt
    reason:       Literal["duplicate", "faulty", "goodwill"]
    currency:     Literal["EUR", "GBP", "USD"] = "EUR"

TOOL_SCHEMAS = {"refund": RefundCall, "search_notes": SearchCall}

def gate_1(name: str, args: dict) -> Result:
    schema = TOOL_SCHEMAS.get(name)
    if schema is None:
        return Reject("GATE 1", f"no tool has the name {name!r}")
    try:
        return Accept(schema.model_validate(args))
    except ValidationError as e:
        return Reject("GATE 1", readable(e))

Low cost, large effect

No database is necessary. The gate stops a call to a tool that does not exist, and an argument that the model invented.

Do not permit extra fields

One line. Without it, the system ignores force=true today, and obeys it after a person adds that parameter.

Write the cause for a reader

The text goes back to the model. “amount_cents must be more than 0” corrects the next attempt.
