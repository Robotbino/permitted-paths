Part 3 · which graph do you mean?

Four things have the name “graph”

control

Execution graph

What comes next?

Nodes are units of work.

The design is permanent. Each run is one pass.

data

Knowledge graph

What is in the domain?

Nodes are entities: a customer, a file.

Continues across runs.

data

Context graph

What occurred in this run?

Nodes are steps, tool calls and records.

Permanent. Each run adds a trace.

control

Procedural graph

Which paths are permitted?

Nodes are steps of a procedure.

Permanent. Many runs use it again.

Control and data. A procedural graph is data that a harness loads. An execution graph is code that the runtime enforces.

Two causes of confusion. GraphRAG is about data, not control. A context graph is a graph of traces. It is not the context window of a model.
