What stays probabilistic

The model decides

  • The text of the plan
  • The text of the code
  • The words of the review

The structure decides

  • The sequence of the steps
  • Which values and types are valid
  • If a person must give approval
  • If the test results must be satisfactory
  • The maximum number of attempts
  • What “complete” means

This is the aim. The model can write and reason. The model cannot change the rules.
