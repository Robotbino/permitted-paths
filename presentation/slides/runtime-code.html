The runtime is fourteen lines

run

obeys the edges · counts · writes the trace

def run(state, start="classify", max_steps=24):
    node = start
    for step in range(max_steps):
        kind, fn = NODES[node]
        began = time.monotonic()
        state = fn(state)         # 1 · a model can operate only here
        trace.write(state.run_id, step, node, kind, state, began)
        if node in TERMINAL:
            return state
        if node == "verify" and not state.tests_pass:
            state = state.with_(attempts=state.attempts + 1)
        node = EDGES[node](state)     # 2 · code selects the path

    return hand_to_person(state)  # 3 · no end: a person gets the run

A framework is not necessary at the start. The runtime obeys the edges, counts the attempts, and writes a trace for each step.

1 · One place for the model

The model operates in a node. It operates in no other line.

2 · Code selects the path

The edge reads the state and gives the next node. The attempt limit is in the edge.

3 · A person at the end

After the maximum number of steps, a person gets the run.

PART 2

Point at the last line. Most agent incidents are not a wrong answer; they are a run that never stopped. A hard step limit with a person at the end of it costs one line and removes that whole class of failure. The three numbered comments match the three notes on the right: one place for the model, code selects the path, a person at the end.
