The runtime is about twenty lines

You do not need a framework to start. You need a walker that obeys the edges, counts the attempts, and writes a trace for every step.

def run(state: RunState, start: str = "classify", max_steps: int = 24) -> RunState:
    node = start
    for step in range(max_steps):
        kind, fn = NODES[node]
        began = time.monotonic()
        state = fn(state)           # the only place a model can run
        trace.write(state.run_id, step, node, kind, state, began)

        if node in TERMINAL:
            return state
        if node == "verify" and not state.tests_pass:
            state = state.with_(attempts=state.attempts + 1)

        node = EDGES[node](state)    # code picks the path, every time

    return hand_to_person(state)     # a run that will not end is a person's problem

Three limits in fourteen lines: a maximum number of attempts on the retry edge, a maximum number of steps in the whole run, and a person at the end of both.

Point at the fallthrough on the last line. Most agent incidents are not a wrong answer; they are a run that never stopped. A hard step limit with a person at the end of it costs one line and removes that whole class of failure.
