Part 8 · give it back

Can you give the ideas back without help?

Four questions

Answer each in your own words: why does the output change, what does a graph remove, what does an ontology add, and what does a gate check?

Four failures

Name the control that each failure needed. If two controls fit, say which one you would build first, and why.

Your run as a context graph

Draw this session as a trace: the steps, what each one read, and where a wrong answer would have been caught.

Your one page

One page for one system you own: the nodes, the permitted results, and the check before each change.

In part 0, the full system was one drawing. In part 8, six arrows lose their labels and you put them back — without help.
