EDGES = {
  "classify": lambda s: "plan" if s.kind == "change" else "answer",
  "plan":     lambda s: "approve",
  "approve":  lambda s: "change" if s.approved else "escalate",
  "change":   lambda s: "verify",
  "verify":   lambda s: (
      "summarise" if s.tests_pass else
      "change" if s.attempts < MAX_ATTEMPTS else
      "escalate"),
}
TERMINAL = {"answer", "summarise", "escalate"}

The kind is in the contract. The colours are the colours of the drawing: model, code, agent, person.

An edge is a function of the state. No model selects the next node. That is control 1.

You can test an edge with no model. Give it a state. Examine the name of the next node.

Example code for teaching

PART 2

Read the verify edge out loud: tests pass means summarise; tests fail means change again, unless we are at the attempt limit, in which case a person takes it. That sentence is now a line of code instead of a line in a prompt. You can unit-test it with no model and no network: feed it a state, assert the next node.
