The same graph, as code

Two dictionaries. The nodes say what runs; the edges say what comes next. No model appears in the edges — that is the whole of control 1.

NODES = {               # what runs, and what kind of thing it is
    "classify":  (MODEL,  classify_request),
    "answer":    (CODE,   answer_from_graph),
    "plan":      (AGENT,  make_plan),
    "approve":   (PERSON, ask_approval),
    "change":    (AGENT,  write_change),
    "verify":    (CODE,   run_tests),
    "summarise": (MODEL,  write_summary),
    "escalate":  (PERSON, hand_to_person),
}
EDGES = {               # who comes next: pure functions of the state
    "classify": lambda s: "answer" if s.kind == "question" else "plan",
    "plan":     lambda s: "approve",
    "approve":  lambda s: "change" if s.approved else "escalate",
    "change":   lambda s: "verify",
    "verify":   lambda s: ("summarise" if s.tests_pass
                    else "change" if s.attempts < MAX_ATTEMPTS else "escalate"),
}
TERMINAL = {"answer", "summarise", "escalate"}

Read the verify edge out loud: tests pass means summarise; tests fail means change again, unless we are at the attempt limit, in which case a person takes it. That sentence is now a line of code instead of a line in a prompt. You can unit-test it with no model and no network: feed it a state, assert the next node.
