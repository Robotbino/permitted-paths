The default is one loop with a strict verifier

Add a graph when a specific problem occurs. One clear “yes” in the right column is sufficient.

Question about the taskOne loop is sufficientUse a graph
Can you write the task as one instruction?YesNo. The task goes from one role to a different role.
Does each step use the same model and tools?YesNo. Some steps use a small model, some a large one.
Are some steps independent?NoYes, and they can operate at the same time
Who decides the result is good?A check in the loop, for example the testsA node that did not write the result
What must occur after a failure of one step?Try againIsolate the failure. The other work continues.
Who must read the record of the path?Only your teamA person outside the team must see which step occurred, and why

Three good causes for a new node: specialization, parallel work, and independent verification. Do not use a graph when the task is open and you cannot give its steps before the run — use an agent harness. If all the steps are code, a script is sufficient.
