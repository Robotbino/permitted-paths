## What you must know about the copies

- **The notes are drafts made with a model.** Each note has the mark `verified: false`. The course does not give a statement with more confidence than the notes give. [`docs/EVIDENCE.md`](../docs/EVIDENCE.md) gives the status of each claim.
- **The images are not here.** For seven of the ten images of the notes, the permission of the owner is necessary before publication. Each copy has a line in the position of each image, and the line that gives the source stays. The course shows a new drawing of the same content.
- **The links between the notes** are usual markdown links to the files in this folder.
- **The originals are not in this repository.** A change to a copy does not change the original. If the originals change, make the copies again.
